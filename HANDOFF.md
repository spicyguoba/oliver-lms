A 400-ply practice limit saves a long game without calling it a chess draw. The library recognizes common insufficient-material draws, not every theoretically dead position.

lib/chess-engine.mjs is a bounded local computer search with five club levels (random legal through iterative deepening to four plies, material/position evaluation and node/time budgets). Labels are not Elo ratings. Hints are useful engine suggestions, not perfect-play guarantees. No external AI provider, API key, child-data transmission or model fee is involved. In addition to normal starting positions, three server-defined practice starts provide king+queen, king+rook and two-rook endgames with read-aloud strategy guides. Bonuses remain idempotent.

A pending help quiz freezes that board's moves until it is finished or closed. Grants bind to the game and position version and are issued once inside the same locked transaction as final grading. A hint highlights from/to and persists only for that position; another hint is unavailable until a new move. Undo removes the last learner move and the computer reply (or just the learner's terminal move), recording all removed moves and the earlier outcome in an undo audit. It is available after a stalemate/checkmate as a learning retry. Full move replay reconstructs castling rights, en passant and repetition; storing only the final FEN would lose repetition history. Past match finishes remain recorded. Starting a fresh computer game retains the old board in history; lessons can be practised without losing the saved full game.

Board input supports tap/tap, legal-square indicators, keyboard arrows/Enter, Black-side orientation and a promotion chooser. Modal focus stays inside quizzes/promotion. ## Important product boundaries

- Original-origin localStorage is still intact at the GitHub Pages site; the new domain cannot automatically import it. LMS copies have separate browser/cloud saves, with original key names. Cloud saves for legacy games use last-write-wins; do not play one legacy game concurrently on multiple devices.
